# چاپ گزارش — نسخه HTML 1.2.0

۱. فایل HTML را در Chrome یا Edge باز کنید و مشخصات ماشین را وارد کنید.
۲. در قسمت «لوگوی گزارش چاپی»، فایل اصلی PNG، JPG یا WebP یکان را انتخاب کنید. تصویر بدون تغییر طرح، با حفظ نسبت ابعاد در هدر چاپ قرار می‌گیرد.
۳. برای همراه‌بودن لوگو با فایل آفلاین، دکمه «ذخیره HTML با لوگو» را بزنید. فایل ذخیره‌شده خود تصویر را درون HTML دارد و به اینترنت یا فایل تصویر جداگانه نیاز ندارد.
۴. دکمه «چاپ نتیجه» را بزنید. گزارش اختصاصی از آخرین ورودی‌های فرم ساخته می‌شود؛ خود فرم چاپ نمی‌شود. Ctrl+P نیز همین گزارش را آماده می‌کند.
۵. کاغذ A4، جهت عمودی و مقیاس ۱۰۰٪ را استفاده کنید. برای جلوگیری از عنوان/آدرس اضافی مرورگر، گزینه Headers and footers مرورگر را خاموش کنید. پس‌زمینه‌های رنگی اختیاری‌اند و بدون آن‌ها هم برچسب‌ها خوانا هستند.

گزارش شامل عنوان «راهنمای انتخاب رنج ترانسمیتر ارتعاش»، سایت www.Yekan-Vibro.com، مشخصات ماشین، حد آلارم B/C، حد توقف C/D، رنج سنسور و جریان ۴–۲۰ میلی‌آمپر است. برچسب‌ها «حد آلارم» و «حد توقف» هستند و پیشوند «در» ندارند. ارتفاع محور فقط برای موتور و رده کاربرد فقط برای پمپ گزارش می‌شود.

حد آلارم عدد B/C و حد توقف عدد C/D است. ارتعاش پایه، این دو مرز را تغییر نمی‌دهد. جریان هر حد از رابطه `4 + 16 × حد / رنج` محاسبه می‌شود.

در انتخاب‌های فاقد جدول عددی یا ورودی نامعتبر، گزارش یک‌صفحه‌ای پیام محدودیت را نشان می‌دهد و نتیجه عددی قبلی را چاپ نمی‌کند.

## وضعیت لوگو

تصویر لوگو در گفتگو دیده شده اما فایل باینری آن در فایل‌های قابل‌دسترسی اجرای این جلسه موجود نبود. بنابراین لوگوی دیگری به جای آن ساخته یا داخل نسخه عمومی درج نشده است. انتخاب تصویر و ذخیره HTML با همان تصویر، برای استفاده از اصل فایل لوگوی کاربر فراهم شده است. اگر لوگویی انتخاب نشده باشد، هدر فقط عنوان و سایت را نشان می‌دهد.

## بررسی نسخه

گزارش هر ۱۱ نوع ماشین با Chromium و تنظیم CSS صفحه A4 تولید و با pypdf تک‌برگی بودن PDF کنترل شد. چاپ با لوگوی آزمایشی، خروجی بدون لوگو، ورودی نامعتبر، حفظ مقدارهای آخر فرم و انتقال تصویر به HTML ذخیره‌شده نیز آزمایش شدند. لوگوی آزمایشی در نسخه دانلودی وجود ندارد.

این نسخه، HTML مستقل است. فایل ZIP قدیمی افزونه وردپرس نسخه 1.0.0 را شامل تغییرهای جدید تلقی نکنید.

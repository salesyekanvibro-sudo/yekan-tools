# چاپ گزارش — نسخه HTML 1.2.5

فایل HTML در مرورگر و بدون نصب اجرا می‌شود. دکمه «چاپ نتیجه» گزارش اختصاصی از آخرین اطلاعات ماشین را می‌سازد؛ لیست‌های کشویی چاپ نمی‌شوند. کاغذ A4، جهت عمودی، مقیاس ۱۰۰٪ و خاموش‌بودن Headers and footers مرورگر توصیه می‌شود.

## لوگوی ثابت

از نسخه 1.2.5، فایل اصلی logo.png از آرشیو logo.rar کاربر بدون بازطراحی یا تغییر بایت‌ها به‌صورت data URL داخل HTML جاسازی شده است. نسخه اصلی نیز برای نگه‌داری در docs/assets/yekan-logo.png ذخیره شده است. مشتری به بارگذاری تصویر، ذخیره تنظیمات یا اتصال اینترنت برای لوگو نیاز ندارد.

لوگو در ستون چپ هدر و عنوان و سایت در ستون راست قرار دارند. کنترل‌های بارگذاری و ذخیره تصویر در رابط مشتری وجود ندارند.

## محاسبات و گزارش

آلارم برابر B/C و توقف برابر C/D است. جریان خروجی از رابطه 4 + 16 × حد / رنج به دست می‌آید. ارتعاش پایه حذف شده است. ارتفاع محور فقط برای موتور و رده کاربرد فقط برای پمپ چاپ می‌شود. استاندارد مرتبط کنار نام ماشین می‌آید.

PDF هر ۱۱ نوع ماشین تک‌برگی آزمایش شده است. چاپ یک‌برگ با لوگوی اصلی جاسازی‌شده و بدون دسترسی شبکه نیز بررسی شد.

این نسخه HTML مستقل است؛ ZIP قدیمی افزونه وردپرس، تغییرات جدید را ندارد.

# مشخصات و قراردادهای پروژه

## نام افزونه وردپرس

نام پایه افزونه در انتشارهای آینده باید دقیقاً عبارت زیر باشد:

`Yekan ISO 20816 Training`

شماره نسخه در انتهای نام قرار می‌گیرد. الگوی کامل نام نمایشی:

`Yekan ISO 20816 Training vX.Y.Z`

برای نمونه:

- `Yekan ISO 20816 Training v1.0.0`
- `Yekan ISO 20816 Training v1.0.1`
- `Yekan ISO 20816 Training v1.1.0`

در سربرگ فایل اصلی افزونه وردپرس، دو مقدار با هم هماهنگ باشند:

```php
Plugin Name: Yekan ISO 20816 Training v1.0.1
Version: 1.0.1
```

شماره بالا نمونه است و هنگام انتشار باید با نسخه واقعی جایگزین شود. این قرارداد برای ساخت و انتشار نسخه‌های بعدی است؛ فایل ZIP قبلاً منتشرشده، سند نسخه تاریخی خود محسوب می‌شود.

## نسخه‌بندی

نسخه فعلی مبنا `v1.0.0` است. برای نسخه‌های بعدی:

- رقم آخر برای اصلاح ایراد و متن‌ها افزایش پیدا می‌کند؛ مانند `v1.0.1`.
- رقم میانی برای قابلیت جدید سازگار افزایش پیدا می‌کند؛ مانند `v1.1.0`.
- رقم اول برای تغییر اساسی ناسازگار افزایش پیدا می‌کند؛ مانند `v2.0.0`.

در هر انتشار، نام نمایشی افزونه، سربرگ `Version`، فهرست تغییرات، تگ گیت و نام بسته دانلود باید شماره نسخه هماهنگ داشته باشند. تغییر صرفاً مستنداتی، انتشار نسخه جدید افزونه محسوب نمی‌شود.

نام پوشه افزونه، شورت‌کدها و کلیدهای تنظیمات ذخیره‌شده مستقل از نام نمایشی هستند؛ تغییر نام نمایشی به‌تنهایی نباید آن‌ها را تغییر دهد.

# تغییرات نسخه وب

## v1.1.1

- کادر «مقادیر نمونه آموزشی» همراه با همه توضیحات، لینک‌ها و دکمه داخل آن از رابط حذف شد.
- بارگذاری پیش‌فرض‌ها و حفظ مقادیر هر ماشین همچنان فعال است.

## v1.1.0

- قاب خاکستری با چهار گوشه گرد، فاصله داخلی یکنواخت و حذف مشکل جمع‌شدن حاشیه بالای فرم اصلاح شد.
- پروفایل‌های آموزشی جداگانه برای هر یازده نوع ماشین اضافه شدند؛ ویرایش‌ها هنگام جابه‌جایی بین ماشین‌ها حفظ می‌شوند.
- دکمه بازگردانی مقادیر نمونه اضافه شد.
- توان و دور روتور توربین بادی از مدل‌های آنلاین NREL/OpenFAST مستند شدند. سایر پروفایل‌ها صریحاً آموزشی هستند؛ محدودیت دسترسی کاتالوگ‌ها در DEFAULTS.md ثبت شده است.
- ارتفاع محور و ارتعاش پایه بدون داده واقعی خالی می‌مانند.

## v1.0.1

- کل بخش آبی بالای صفحه، شامل عنوان، توضیح، نشان یکان و دکمه‌های زبان حذف شد.
- صفحه مستقیماً از فرم مشخصات ماشین شروع می‌شود.
